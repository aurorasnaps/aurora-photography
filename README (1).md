# Aurora Photography — Cinematic Homepage

This is a standalone static website. No paid builder, build command, or JavaScript framework is required.

## Update your existing GitHub repository

1. Back up your existing `index.html` (GitHub also retains its commit history).
2. Open your `aurora-photography` repository and click `index.html`.
3. Click the pencil/Edit button. Replace the file's contents with the contents of this package's `index.html`.
4. Click **Commit changes**. Your connected Cloudflare deployment should redeploy automatically.
5. Visit the deployed URL and refresh.

## Personalize

- Replace the sample Unsplash image URLs in the slide backgrounds and gallery image `src` attributes with paths to your own photos, e.g. `images/portfolio-01.jpg`.
- Replace `YOUR_EMAIL@example.com` with your actual email address in the contact link.
- For real online appointments, create a booking calendar and replace the `href="#contact"` on the element with `id="booking-link"` with your booking URL. Booking is NOT functional until configured.
- Change the brand name, headings, descriptions and social links as desired.
- The sample images are remote placeholders; your own files will make the site independent of external image hosting.

This design is inspired by the user-supplied screenshot but is independently coded and uses placeholder photographs.
